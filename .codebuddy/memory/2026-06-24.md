# 2026-06-24 工作日志

## 修复: build_rv1106.sh RV1106_SDK_INCLUDE 默认值错误

### 问题
`./build_rv1106.sh rv1106` 编译失败：
```
src/rk_camera.c:18:10: fatal error: rk_mpi_sys.h: No such file or directory
```
日志显示 `sdk inc: /usr/include` — 用了 host 的 include 目录。

### 根因
`build_rv1106.sh` 第 83 行：
```bash
export RV1106_SDK_INCLUDE="${RV1106_SDK_INCLUDE:-/usr/include}"
```
默认值 `/usr/include` 是 host 的 include，不是 RV1106 SDK 的。`rk_mpi_sys.h` 在 `$SDK_ROOT/media/rockit/rockit/mpi/sdk/include/`。

### 修复
改为自动检测 rockit include 目录（类似 `RV1106_SDK_LIB` 的自动检测逻辑）：
```bash
ROCKIT_INC="$SDK_ROOT/media/rockit/rockit/mpi/sdk/include"
if [ -f "$ROCKIT_INC/rk_mpi_sys.h" ]; then
    export RV1106_SDK_INCLUDE="$ROCKIT_INC"
else
    echo "[ERROR] rockit include dir not found..."
    exit 1
fi
```
同时把 `SDK_ROOT` 的定义提前到 SDK 路径检测块的开头（原来只在 `RV1106_SDK_LIB` 未设置时才定义）。

## 修复: viewer_cli.rs 编译错误 (player feature)

### 问题
`./play_viewer.sh build` 编译失败，3 个错误：
1. `E0425`: `drain_audio_channel` 循环变量 `_packet` 但用了 `packet.data`
2. `E0382`: `drain_channel`/`drain_audio_channel` 中 `Option<&mut VideoPlayer>`/`Option<&mut AudioPlayer>` 在 while 循环里被 move（传给 `process_video_frame` / `if let Some(ap) =`）
3. `warning`: `use ffmpeg_next::codec::traits::Decoder` unused

### 修复
1. `drain_audio_channel`: `_packet` → `packet`
2. `drain_channel` / `drain_audio_channel`: 参数加 `mut`，循环内用 `player.as_mut().map(|p| &mut **p)` 重新借用（`Option<&mut T>` 不实现 Copy，循环中传值会 move；`.as_mut().map(|p| &mut **p)` 每次产生新的 `Option<&mut T>` 借用）
3. 删掉 unused `Decoder` import（当前 ffmpeg-next 版本 `.decoder()` 不再需要该 trait）

### 关键模式: 循环中传 `Option<&mut T>`
```rust
// ❌ 错误: Option<&mut T> 不 Copy, 循环里 move
fn f(player: Option<&mut Player>) {
    while ... {
        process(player);  // move!
    }
}

// ✅ 正确: 标记 mut + as_mut().map(|p| &mut **p) 重新借用
fn f(mut player: Option<&mut Player>) {
    while ... {
        process(player.as_mut().map(|p| &mut **p));
    }
}
```
