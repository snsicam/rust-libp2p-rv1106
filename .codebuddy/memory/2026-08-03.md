# 2026-08-03

- 构建 viewer Win 版（Debug）：`p2p-camera/scripts/build_viewer.ps1` 之前因 libclang `LoadLibraryExW failed (err=126)` 失败。根因：`LIBCLANG_PATH` 只设了 libclang.dll 路径，但 bindgen 加载时不把该目录加入依赖搜索路径，导致 `bin\libclang.dll` 依赖的 `LLVM-C.dll`/`z.dll`/`zstd.dll` 解析不到。
- 修复：在 `build_viewer.ps1` 里设置 `LIBCLANG_PATH` 后，把该目录前置到 `PATH`（`$env:PATH = "$LIBCLANG_PATH;$env:PATH"`）。重新构建成功：`media_viewer.exe` 22.1MB，产物在 `p2p-camera/target/debug/examples/media_viewer.exe`。已同步经验到 MEMORY.md「libclang 加载失败」节。
- 注意：`pwsh` 不在 PATH，需用 `powershell.exe`；长编译用 `schtasks /IT` 后台任务跑，避免被工具回收进程树。
