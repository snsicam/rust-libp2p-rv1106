# 2026-06-26 工作日志

## 修复: PPS id out of range + DCUtR 外网失败 (真实摄像头外网测试)

### 问题
外网测试（relay 在公网 101.35.90.171, gateway 在 RV1106 内网, viewer 在另一内网）：
1. viewer 第一帧就报 `PPS id out of range: 0` — 缺 VPS/SPS/PPS
2. DCUtR 外网失败 — `Inbound stream error: IO error`

### 问题 1 根因: VPS/SPS/PPS 未被缓存
- VENC 每个 pack 是独立 NAL unit，VPS/SPS/PPS 是独立 pack (`enH265EType` = 32/33/34)
- 旧 C 代码 `is_keyframe` 只判断 19/20 (IDR)，没把 `enH265EType` 传给 Rust
- 旧 Rust `on_frame` 用 `slice.first()` 取第一个字节做 NAL type 判断
- **VENC 输出含 4 字节 start code (00 00 00 01)**，所以 `slice.first()` = 0x00 → nal_type = 0
- VPS/SPS/PPS (32/33/34) 永远不匹配 → `GLOBAL_PARAM_SETS` 为空 → `init_nals` 为空
- viewer 收到的第一帧是 P 帧 (无参数集) → `PPS id out of range: 0`

### 问题 1 修复 (权威 NAL type)
1. **`rk_camera.c`**: 回调签名增加 `nal_type` 参数，直接传 VENC 的 `enH265EType`
   ```c
   typedef void (*frame_callback_t)(const uint8_t *data, uint32_t len, uint64_t pts,
                                     int is_keyframe, int nal_type);
   // ...
   int nal_type = stFrame.pstPack->DataType.enH265EType;
   g_callback(pData, u32Len, u64PTS, is_keyframe, nal_type);
   ```
2. **`rk_video_source.rs`**:
   - `FrameCallback` 类型增加 `nal_type` 参数
   - `on_frame` 用权威 `nal_type`（不再从字节猜）
   - 缓存 VPS/SPS/PPS 时跳过 start code（存储纯 NAL，发送时重新加 start code）
   ```rust
   let nal_start = if slice[0..4] == [0,0,0,1] { 4 }
                   else if slice[0..3] == [0,0,1] { 3 }
                   else { 0 };
   let nal_data = &slice[nal_start..];
   ```

### 问题 2 根因: viewer 用 TCP 连 relay
- viewer 日志: `Dialing relay: /ip4/101.35.90.171/tcp/4001/...`
- TCP 连 relay → identify 只观察 TCP 地址 → DCUtR 只有 TCP 候选
- 外网 TCP 打洞基本不可能（防火墙阻挡 inbound SYN）→ `Inbound stream error: IO error`
- 内网能成功是因为内网防火墙宽松

### 问题 2 修复 (使用方式, 无代码改动)
- viewer 必须用 QUIC 连 relay: `--relay /ip4/101.35.90.171/udp/4001/quic-v1/p2p/...`
- QUIC 连 relay → identify 观察 QUIC 地址 → DCUtR 有 QUIC 候选 → UDP 打洞

### 关键教训
- **Rockchip VENC 输出含 4 字节 Annex B start code**，不能假设第一个字节是 NAL header
- **权威 NAL type 来自 VENC 的 `enH265EType`**，比从字节解析更可靠
- **DCUtR 的候选地址取决于 relay 连接方式**: TCP 连 relay → TCP 候选; QUIC 连 relay → QUIC 候选
